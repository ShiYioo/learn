# Frontend

<Badge type="warning" text="施工中" />

前端（Front-end），狭义上指 Web 网站的前台，即展示在用户面前网站的样子。广义上，前端还包括 App 前端/移动端，桌面端和小程序等等。这里文档所说的 Frontend 属于广义的前端。

## 如何使用

从上到下推进：薄荷青节点是主线里的学习里程碑，浅色节点用于展开该阶段的具体内容。紫色对号代表推荐路线，绿色对号代表替代选择；只会出现在需要作出选择的地方。点击学习节点可记录完成状态，进度只保存在当前浏览器中。路线图草稿可在顶部“工具 → 路线图编辑器”中调整，草稿只保存在当前浏览器，也可导入、导出 JSON。

## 项目建议

完成一个内容型网站或工具型应用：包含真实数据、多个页面、移动端适配与上线地址。项目完成后，回到路线图补上对应节点，找出下一步要补齐的能力。
