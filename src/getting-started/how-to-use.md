# 如何使用

这不是一份必须按顺序通关的课程表，而是一张帮助你做选择、持续复盘的学习地图。

<LumNote>先选一个你现在最需要解决的问题，再沿着对应路线完成一个小项目。学习的节奏可以由你自己决定。</LumNote>

## 从起步开始

如果你还不确定方向，先阅读「大学生开发者」与「Computer Science」，建立基础习惯和知识框架。

## 选择一条主线

从开发方向、AI & Data 或编程语言中选一条作为主线。先做到能独立完成小作品，再扩展第二条方向。

## 用项目检验学习

每学完一个阶段，都用一个可以展示、可以复盘的小项目检验成果。卡住时回到前置知识，而不是盲目堆新课程。
