# 如何使用

如果你最近有玩过新游戏，你会发现它们的开头，往往是以一段新手教程开始。

它会教你如何移动，如何攻击，如何使用技能 ...

<LumNote>不管是学任何技能，从简单的事情出发往往更容易坚持哦。</LumNote>

## 1. 作为新手教程

学习 CS 同样如此，新手教程是必不可少的，

它能让从未接触的人快速了解机制，提高兴趣

所以请把本文档当作一份学习 CS 的新手教程或者攻略指南。

## 2. 认识文档目录

如果你是桌面端访问，你会看到左侧一竖列的文档目录导航，你可以切换查看不同类别。

是移动端也没关系，你可以点击左上角的 Menu 查看 （不过在有条件下更推荐使用桌面端阅读本文档，能获取更好的阅读体验）。

目录目前有八个栏目，

- **起步** （<- 当前栏目）
  - 简介
  - 如何使用
  - ...
- **🚀 开发方向**（<- 学习的大方向，与未来工作职位有直接关系）
  - Frotend
  - Backend
  - ...
- **🤖 AI & Data**（<- 近期新热门的开发方向）
  - AI Engineer
  - ...
- **💻 编程语言**（<- 往往根据开发方向选择的语言，但也有语言可以从事多个方向）
  - Python
  - JavaScript
  - ...
- **🧰 核心技能**（<- CS 通用技能，学习了往往好处很大）
  - Git & GitHub
  - Linux
  - ...
- **💼 求职准备**（<- 扩展，为以后求职投递做准备）
  - 简历怎么写
  - ...
- **📚 学习资料**（<- 扩展，分享日常可以看的学习资料）
  - 书籍推荐
  - ...
- **贡献与维护**（<- 贡献本文档的指南）
  - 如何参与贡献
  - ...

## 3. 确定方向

对目录有了认识后，就可以开始使用本文档了。

如果你还不确定方向，推荐继续阅读「开发者基础」，里面有较详细的开发方向和编程语言相关介绍。

## 4. 选择一条主线

确定好方向之后就很简单了，选择一条作为主线，然后不断的提升自己吧。

> 学习的方法有很多，就像游戏里可以查攻略，也可以不断实战总结经验等等。
>
> 无论哪个，适合自己的才是最好的。

## 5. 适当的输出

但还是要提个醒，尽管现在 AI Coding 工具已经足够好用，但是不要沉迷其中。

只有过硬的基础和思维能力才是属于自己的，对于现在，学习基础仍然是最推荐的，而不是直接 AI 一把梭。为了避免这样，请确保自己有持续的代码或知识输出。

> 编程是块肌肉，会愈练愈强，也会在懈怠中退化。
